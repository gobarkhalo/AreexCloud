Razorpay Configuration

ℹ️ Get your API keys from dashboard.razorpay.com → Settings → API Keys. Use Live keys for real payments.

How to Apply Your Key

After saving your Key ID above, open index.html and find this line near the top of the <script>:

const RAZORPAY_KEY = 'rzp_test_REPLACE_WITH_YOUR_KEY';

Replace rzp_test_REPLACE_WITH_YOUR_KEY with your actual Key ID (starts with rzp_live_ or rzp_test_) and save the file. That's it — payments will now go directly to your Razorpay account.
